About the Project
This repository contains three simple website interface projects created using HTML and internal CSS as part of web development practice.
Projects
1. Online Shopping Website — Case 6
An e-commerce interface that displays products and includes:
- Product images and descriptions
- Prices, discounts, and ratings
- Product categories
- Shopping buttons
- Promotional banners and navigation
- Responsive product grid
2. Hotel Reservation Website — Case 18
A hotel website interface that includes:
- Room categories and images
- Facilities and tariffs
- Check-in and check-out fields
- A reservation form
- Room cards and booking sections
3. Movie Review and Rating Website — Case 22
A movie website interface that includes:
- Movie posters
- Genres and release dates
- Cast information and synopses
- Reviews and ratings
- Responsive movie cards
Technologies Used

- CSS3 (internal CSS)

2. Open the project folder in Visual Studio Code or another code editor.
3. Find the HTML file for the project you want to view.
